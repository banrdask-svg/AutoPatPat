# Auto PatPat

Клиентский мод Fabric для Minecraft 1.21.11: автоматический PatPat, списки игроков и защита друзей. Требуется Java 21 и Fabric API.

Для сборки нужен Gradle и PatPat 1.3.1 для Fabric 1.21.11: поместите файл PatPat-1.3.1+1.21.11+fabric.jar в корень проекта, затем запустите gradle build. Сторонний PatPat в репозиторий не включён.
